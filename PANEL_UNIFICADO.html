¿Estás instalando en una PC nueva?

Ejecuta INSTALAR_UNIFICADO.ps1 desde PowerShell, inicia Apache y MySQL, importa database/schema.sql si la base es nueva y compila con npm ci y npm run build. Si tu carpeta anterior está incompleta, el instalador la conserva como respaldo.
